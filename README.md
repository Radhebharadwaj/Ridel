## 🍎 Pending iOS Native Setup (Mac Required)

- [ ] Open `ios/Runner.xcworkspace` in Xcode (Must be on a Mac).
- [ ] Click on the `Runner` project in the left navigator.
- [ ] Go to the `Signing & Capabilities` tab.
- [ ] Click `+ Capability` and add `Push Notifications`.
- [ ] Click `+ Capability` again, add `Background Modes`, and check the `Remote notifications` box.
